## Limits

No stress tests, signing, transactions, backup restore, failure injection, or prover checks were performed in this sub-audit. Python urllib received HTTP403 for RPC while curl succeeded, so initial Python failures are not treated as service outages. Several optional zks RPC methods return method-not-found; the portal-used `zks_getL2ToL1LogProof` is supported and returned null for a nonexistent transaction, so method coverage was not mislabeled as a portal blocker.
